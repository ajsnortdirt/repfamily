polityka prywatności

Ostatnia aktualizacja: 19 maja 2026

rep.family ("strona") szanuje prywatność użytkowników. Niniejsza polityka wyjaśnia jakie dane są zbierane podczas korzystania ze strony oraz w jaki sposób są przetwarzane.

1. Jakie dane zbieramy

Cloudflare Web Analytics — strona używa anonimowej analityki Cloudflare, która zbiera ogólne dane techniczne o wizytach: kraj, typ urządzenia, przeglądarka, ścieżka URL, czas wczytania strony. Dane są agregowane, bez identyfikatorów osobowych. Brak plików cookie.

localStorage — w przeglądarce użytkownika zapisywany jest zachowany kurs USD/PLN (cache 6h), aby nie odpytywać zewnętrznego API przy każdym wejściu. Można wyczyścić przez "wyczyść dane przeglądarki".

Service Worker / Cache — pliki strony (HTML, CSS, JS, obrazki) są lokalnie buforowane przez przeglądarkę, dzięki czemu strona działa szybciej i offline. Cache można wyczyścić w ustawieniach przeglądarki.

2. Czego NIE zbieramy

  • Adresów IP (Cloudflare przetwarza je technicznie do dostarczania strony, ale nie są przechowywane przez rep.family)
  • Adresów email
  • Imion, nazwisk, danych adresowych
  • Danych płatniczych — strona nie sprzedaje żadnych produktów, jest jedynie zbiorem linków
  • Plików cookie służących do śledzenia

3. Linki zewnętrzne

Strona zawiera linki do zewnętrznych serwisów, w szczególności KakoBuy z parametrem partnerskim affcode=repfamily. Po kliknięciu opuszczasz rep.family i podlegasz polityce prywatności:

  • KakoBuy oraz serwisów źródłowych (Taobao, Weidian, 1688, Tmall, JD, Goofish)
  • Discord — w przypadku kliknięcia ikony Discord
  • 17track.net — w przypadku korzystania z modułu śledzenia paczek

rep.family nie ponosi odpowiedzialności za sposób przetwarzania danych przez te zewnętrzne podmioty.

4. Cloudflare

Strona jest dostarczana przez sieć Cloudflare, która może przechowywać logi techniczne (anonimowe) w celu zapewnienia bezpieczeństwa i wydajności. Szczegółowa polityka Cloudflare: cloudflare.com/privacypolicy.

5. Hosting

Strona hostowana jest na infrastrukturze GitHub Pages. GitHub Inc. może zbierać dane techniczne zgodnie ze swoją polityką: GitHub Privacy Statement.

6. Twoje prawa (RODO)

Jeśli przebywasz na terenie Unii Europejskiej, masz prawo do informacji o przetwarzaniu danych osobowych. Ponieważ rep.family nie zbiera samodzielnie danych osobowych w rozumieniu RODO, nie przechowuje żadnych danych, które można by usunąć lub udostępnić.

W zakresie danych technicznych przetwarzanych przez Cloudflare i GitHub — prawa użytkownika reguluje polityka tych usługodawców.

7. Kontakt

8. Zmiany w polityce

Polityka może być aktualizowana w razie zmian w działaniu strony lub przepisów prawa. Aktualna wersja zawsze dostępna pod adresem rep.family/privacy.
